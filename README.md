# Claude CLI Ledger

This private Markdown ledger tracks Claude CLI delegation status, run logs, handoff packets, and governance rules.

It intentionally stores summaries only. Do not commit full transcripts, API keys, tokens, cookies, passwords, private keys, or reusable session credentials.

## Current Files

- `dashboard.md`: sanitized active dashboard.
- `logs/`: per-run logs.
- `rules/`: governance and delegation mechanism.
- `templates/`: reusable templates.

## Operating Rule

Use one active Claude CLI task by default. Use this ledger as the source of truth for state, decisions, risks, and next actions.
